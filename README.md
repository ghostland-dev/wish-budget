# Ma Wishlist

Wishlist manager with budget tracking, also packaged for mobile.

## Features

- Wishlist by category
- Budget tracking
- Android/iOS via Capacitor

## Tech Stack

- Vite
- React
- TypeScript
- Tailwind CSS
- shadcn/ui (Radix UI)
- TanStack Query
- React Router
- Capacitor

## Getting Started

```bash
git clone https://github.com/ghostland-dev/wish-budget.git
cd wish-budget
npm install
npm run dev
```

Other scripts:

- `npm run build`: vite build
- `npm run lint`: eslint .
- `npm run preview`: vite preview
